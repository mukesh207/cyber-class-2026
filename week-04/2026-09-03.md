## 1. What is it?
This session covers the foundational mechanics of how devices are addressed and grouped on a network.
- **IPv4**: Internet Protocol version 4. A 32-bit address format divided into 4 "octets" (e.g., `192.168.1.1`).
- **IPv6**: Internet Protocol version 6. A 128-bit address format created to replace IPv4 due to address exhaustion.
- **Subnetting**: The process of dividing a single large network into multiple smaller, manageable logical networks (subnets).
- **Subnet Mask**: A 32-bit number that masks an IP address and divides the IP address into two parts: the **Network ID** and the **Host ID**.
- **0.0.0.0**: In IPv4, this represents "all IPv4 addresses on the local machine" (when listening/binding to ports) or a default route.

## 2. Why does it happen?
Why do we need subnets and masks? 
If every computer in a company was on the exact same network layer, every broadcast message (like ARP asking "Who has this IP?") would go to every single computer. This creates massive congestion ("broadcast storms"). 
**Subnetting** shrinks these broadcast domains, improving network performance, organization, and security (by allowing firewalls to filter traffic between subnets). 

## 3. How does it work?
An IPv4 address is 32 bits long, split into 4 sections (octets) of 8 bits each.

```text
Format:    [ Octet 1 ] . [ Octet 2 ] . [ Octet 3 ] . [ Octet 4 ]
Example:       192     .     168     .      1      .     10
Binary:     11000000   .  10101000   .  00000001   .  00001010
```

**Network vs. Host Identification**
The **Subnet Mask** dictates which part of the IP identifies the neighborhood (Network) and which part identifies the specific house (Host).
We use **CIDR (Classless Inter-Domain Routing)** notation to write masks quickly:
- `/8` = `255.0.0.0` (First octet is Network, last three are Hosts)
- `/16` = `255.255.0.0` (First two are Network, last two are Hosts)
- `/24` = `255.255.255.0` (First three are Network, last one is Host)
- `/32` = `255.255.255.255` (Identifies one exact, specific host—no network).

## 4. Where is it used / found?
- Configuring static IP addresses on a server or workstation (e.g., `/etc/network/interfaces` or NetworkManager).
- DHCP Servers determining what range of IPs to hand out.
- Cloud environments (AWS VPCs, Azure VNets) where you must design your own subnets.
- Firewall rules (e.g., allowing traffic from `10.0.0.0/8` but blocking others).

## 5. How do I identify it?
When you look at an IP address configuration, you will usually see the CIDR notation appended to the IP, or a separate subnet mask.
- Notation 1: `192.168.1.10/24`
- Notation 2: `IP: 192.168.1.10, Netmask: 255.255.255.0`

By looking at the mask, you identify the **Network ID** by keeping the network bits and turning all host bits to 0 (e.g., `192.168.1.0`).

## 6. Hands-on / Lab Methodology
**Goal: Simple IP Calculation and Subnet Mapping**
- **What to observe first:** The target IP address and its subnet mask.
- **Attack surface:** If two targets are in the same subnet (e.g., `/24`), you can reach them directly via Layer 2 (ARP). If they are in different subnets, your traffic must pass through a router.
- **Initial hypothesis:** We need to figure out the boundaries of the network to know how many targets exist.
- **What to test:** Use an IP calculator tool to find the Network Address, Broadcast Address, and Host Range.
- **How to test it safely (authorized lab):** 
  - Run `ipcalc 192.168.1.10/24` in your terminal.
- **Expected result:** The tool will output the network bounds.
- **How to interpret the result:** 
  - Network Address (Cannot be assigned to a device)
  - Usable Host Range (The IPs you can scan or target)
  - Broadcast Address (The last IP, used to message everyone on the subnet)

## 7. Failed Attempts & Why
- **What was tried:** Trying to assign the IP `192.168.1.255/24` to a new server.
- **Why it failed:** The system rejects it because it is the **Broadcast Address** for that subnet. 
- **What that tells us:** In every subnet, you always lose 2 IPs. The very first IP (all host bits 0) is the Network ID, and the very last IP (all host bits 1) is the Broadcast Address.
- **What to try next:** Assign an IP between `.1` and `.254`.

## 8. Example
Let's do a simple calculation with `10.0.0.50 /24`.
- The `/24` means the first 3 octets (`10.0.0`) belong to the network.
- The last octet (`.50`) is the host.
- **Network ID:** `10.0.0.0`
- **First Usable Host:** `10.0.0.1`
- **Last Usable Host:** `10.0.0.254`
- **Broadcast Address:** `10.0.0.255`
- **Total usable hosts:** 2^8 - 2 = 254 hosts.

## 9. Impact
From a security perspective, improper subnetting (making the network too large, like a `/8` internal network) means if one machine gets infected with malware, it can blast ARP requests and worm its way across thousands of machines without ever passing a firewall.

## 10. Detection
Defenders and SOC analysts monitor subnet traffic to detect anomalies. If a host in the HR subnet (`10.1.1.0/24`) suddenly starts port-scanning the Server subnet (`10.2.2.0/24`), firewalls and IDS systems detect this cross-subnet communication.

## 11. Prevention / Remediation
Network Segmentation. Group related devices into small, tight subnets (e.g., `/24` or `/26`) and force them to route through a firewall to talk to other subnets. This limits lateral movement for attackers.

## 12. Related Concepts
- Connects back to **Session 01 (Networking Fundamentals)**.
- Relates to **Nmap scanning**: When you run `nmap 192.168.1.0/24`, you are utilizing CIDR notation to tell Nmap to scan all 256 IPs in that block.

## 13. Important Commands / Syntax
- `ip a` or `ifconfig`: View your current IP and subnet mask on Linux.
- `ipcalc <IP/CIDR>`: A command-line tool that automatically calculates the network, broadcast, and host range.
- `ping -b <Broadcast IP>`: Send a ping to the broadcast address to see who responds (though many modern OSes ignore broadcast pings for security).

## 14. Interview Questions
- **Q: How many bits are in an IPv4 address, and how many in an IPv6 address?**
  IPv4 has 32 bits (4 octets). IPv6 has 128 bits.
- **Q: What is a Subnet Mask?**
  A 32-bit number that masks an IP address, dividing it into the Network identifier and the Host identifier.
- **Q: In a `/24` network, how many usable hosts are there and why?**
  There are 254 usable hosts. A `/24` leaves 8 bits for the host (2^8 = 256). We subtract 2 because the first address is the Network ID and the last is the Broadcast address.
- **Q: What does `0.0.0.0` mean?**
  Depending on context, it usually means "all IPv4 addresses on the local machine" when listening for connections, or a default route (0.0.0.0/0) pointing to the internet.

## 16. Key Takeaways
- IPv4 is 32-bit (4 octets); IPv6 is 128-bit.
- A subnet mask draws the line between the Network portion and the Host portion of an IP.
- `/8`, `/16`, and `/24` are CIDR notations representing how many bits are locked for the network.
- You always lose 2 IP addresses per subnet (Network ID and Broadcast).
- Subnetting is critical for reducing broadcast traffic and creating security boundaries.
- `ipcalc` is a rapid tool for doing subnet math.

## 17. One-Minute Revision
An IPv4 address contains 32 bits divided into 4 octets. To organize networks, we use Subnet Masks (or CIDR notation like `/24`) to divide the IP into a Network ID (the neighborhood) and a Host ID (the specific house). A `/24` leaves 8 bits for hosts, giving 254 usable addresses (subtracting the Network and Broadcast IPs). Subnetting improves performance and security by segmenting traffic. We use tools like `ipcalc` to quickly find network boundaries and ranges before launching network scans.
