## 🦋 What is Burp Suite?

**Burp Suite** (developed by PortSwigger) is the industry-standard software for web application security testing. It is an all-in-one platform used by penetration testers and bug bounty hunters to map out applications, find vulnerabilities, and exploit them.

### The Intercepting Proxy
At its core, Burp Suite acts as an **Intercepting Proxy**.

**How it works:**
Normally, your web browser communicates directly with the web server:
`Browser ◄────────(HTTPS)────────► Web Server`

When you set up Burp Suite, it sits in the middle (acting as a local server on your machine, usually at `127.0.0.1:8080`):
`Browser ◄──► Burp Suite Proxy ◄──► Web Server`

**Why is this powerful?**
Because Burp Suite intercepts the traffic *before* it reaches the server (and before it reaches your browser on the way back), you can **pause, inspect, and modify** every single HTTP request and response. You can change hidden form fields, modify cookies, inject SQL payloads, or bypass client-side validation restrictions.

## ⚙️ Basic Setup & Proxy Configuration

To use Burp Suite effectively, you must configure your web browser to route all its traffic through Burp Suite. While Burp has a built-in browser, learning to configure your own browser (like Firefox) is an essential skill.

### Step 1: Start Burp Suite
1. Launch Burp Suite Community Edition.
2. Select **Temporary Project** (Community edition does not allow saving projects to disk) → Click **Next**.
3. Select **Use Burp defaults** → Click **Start Burp**.
4. Navigate to the **Proxy** tab, and then the **Proxy settings** sub-tab. Ensure the listener is running on `127.0.0.1:8080`.

### Step 2: Configure the Browser (FoxyProxy)
Manually changing network proxy settings deep in your OS or browser settings every time you want to hack is tedious. Instead, we use a browser extension.

1. **Install FoxyProxy:** Install the "FoxyProxy Standard" extension in Firefox.
2. **Add a Proxy:**
   - Open FoxyProxy settings.
   - Click **Add**.
   - **Title:** Burp Suite
   - **Proxy IP:** `127.0.0.1`
   - **Port:** `8080`
   - Save the configuration.
3. **Turn it on:** Click the FoxyProxy icon in your browser toolbar and select "Burp Suite". All your browser traffic is now flowing to Burp!

### 💡 Common Mistake
If you turn on FoxyProxy but Burp Suite is closed, your browser will say "Proxy server refusing connections" and you won't be able to load any websites. Remember to turn FoxyProxy back to "Disable" when you are done hacking!

## 🔐 Installing the PortSwigger CA Certificate

**The Problem:**
Modern websites use HTTPS (TLS encryption). If Burp Suite intercepts HTTPS traffic, it acts like a Man-in-the-Middle (MitM) attacker. Your browser will detect this and show a giant red warning: `SEC_ERROR_UNKNOWN_ISSUER`, refusing to load the site.

**The Solution:**
You must install Burp Suite's unique Certificate Authority (CA) certificate into your browser. This tells your browser: *"Trust Burp Suite. It is allowed to decrypt and re-encrypt my HTTPS traffic."*

### How to Install the Certificate:
1. Ensure Burp Suite is running and FoxyProxy is set to "Burp Suite".
2. In your browser, navigate to: `http://burp`
3. Click the **CA Certificate** link in the top right corner to download the `cacert.der` file.
4. Go to Firefox **Settings** → Search for "Certificates" → Click **View Certificates**.
5. Go to the **Authorities** tab → Click **Import**.
6. Select the `cacert.der` file.
7. **Crucial Step:** Check the box that says **"Trust this CA to identify websites"**.
8. Click **OK**.

Your browser will now seamlessly load HTTPS websites through Burp Suite without warnings.

## 🛑 Intercepting Your First Request

1. Go to the **Proxy** tab in Burp Suite, then the **Intercept** sub-tab.
2. Ensure the button says **Intercept is on**.
3. Go to your browser (with FoxyProxy set to Burp) and navigate to `http://example.com`.
4. The browser will appear to "hang" or infinitely load.
5. Look at Burp Suite — the HTTP GET request is captured and paused on the screen!
6. **Action:** Click **Forward** to send the request to the server, or **Drop** to kill the request completely.

## 🗂️ Burp Suite Core Tabs Overview

As a beginner, you will spend 90% of your time in these three tabs:

| Tab | What it does | Real-World Use Case |
|-----|--------------|---------------------|
| **Proxy** | Intercepts, views, and modifies HTTP requests and responses in real-time. | Pausing a login request to change your username from `user` to `admin' OR 1=1--`. |
| **Repeater** | Allows you to manually edit and re-send a single captured request over and over. | Testing different SQL injection payloads on a specific search bar without using the browser. |
| **Intruder** | Automates sending many requests with slightly modified payloads (Fuzzing). | Brute-forcing a login page with a dictionary list of passwords (rate-limited in Community Edition). |
| **Target** | Builds a site map of the target application as you browse. | Discovering hidden endpoints or mapping out the folder structure of the web app. |
| **Decoder** | A tool for encoding/decoding data (Base64, URL, HTML, etc.). | Decoding a mysterious Base64 cookie you found in a request. |

### 🧠 Remember
The general workflow is: **Proxy** (capture the request) → **Send to Repeater** (Ctrl+R / Cmd+R) → **Repeater** (modify and test repeatedly).

## 🎯 Interview Q&A

**Q: What is Burp Suite and what is its primary function?**
> Burp Suite is an industry-standard web application security testing platform. Its primary function is acting as an **Intercepting Proxy**, allowing testers to capture, inspect, and modify HTTP/HTTPS traffic between the browser and the web server.

**Q: Why do we need to install the PortSwigger CA Certificate?**
> Because Burp Suite acts as a Man-in-the-Middle. If you try to intercept HTTPS traffic without the certificate, the browser will block the connection due to an unknown issuer. Installing the CA certificate tells the browser to explicitly trust Burp Suite to decrypt the traffic.

**Q: What is FoxyProxy and why do pentesters use it?**
> FoxyProxy is a browser extension that allows you to quickly toggle proxy settings on and off. Pentesters use it so they don't have to manually dig into their OS or browser network settings every time they want to route traffic through Burp Suite.

**Q: What is the difference between the Proxy tab and the Repeater tab?**
> The **Proxy** tab intercepts live traffic flowing between the browser and the server. The **Repeater** tab takes a *single* captured request from the Proxy and lets you manually modify and re-send it as many times as you want without involving the browser again.

**Q: What happens if you leave your browser configured to use the Burp Proxy, but you close the Burp Suite application?**
> Your browser will fail to load any webpages, returning a "Proxy server refusing connections" error, because it is trying to send traffic to a local server on port 8080 that is no longer running.

Today we covered the foundational tool of web application hacking: **Burp Suite**.
