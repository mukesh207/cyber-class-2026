## 🔑 Key High-Yield Core Takeaways

1. **Client-Side Attacks & Framing Protections:**
   - **Clickjacking:** Exploits cookie ambient authority and CSS stacking (`opacity: 0.0001`, `z-index: 999`) to trick victims into triggering sensitive actions inside an invisible `<iframe>`.
   - **Framebusting Flaw:** Defeated by HTML5 `<iframe sandbox="allow-forms allow-scripts">` which prevents top-level URL navigation while permitting form submissions. Mitigate strictly via HTTP headers: `X-Frame-Options: DENY` or CSP `frame-ancestors 'none'`.
   - **Watering Hole Attacks:** Adversaries compromise trusted industry websites frequented by target personnel, deploying selective IP/subnet filters to deliver zero-day payloads strictly to victim organizations while evading external crawlers.

2. **Data-Tier Attacks & Character Encoding:**
   - **WAF Impedance Mismatch:** Occurs when a WAF decodes an input once (e.g., `%2527` -> `%27`) and passes it to a backend that decodes it a second time (`%27` -> `'`), bypassing inspection filters. Overlong UTF-8 (`%C0%AF` for `/`) exploits non-compliant multi-byte decoders.
   - **NoSQL Injection:** Exploits unparsed JSON/BSON body ingestion in document stores (MongoDB) by supplying operators like `{"$ne": null}` or `$regex` to bypass authentication and extract data without relational SQL syntax. Automated with **NoSQLMap**.
   - **SQLMap:** Detects and exploits injection using 6 formal techniques (**BEUSTQ**): Boolean blind, Error-based, Union query, Stacked queries, Time-based blind, and Inline/OOB queries.

3. **Comparative Tool Architecture:**
   - **ZAP:** Java-based open-source DAST engine ideal for automated headless CI/CD pipeline scans.
   - **Burp Suite:** Enterprise Java proxy featuring manual repeater, 4 intruder attack modes (Sniper, Battering Ram, Pitchfork, Cluster Bomb), and Burp Collaborator for blind out-of-band (OOB) validation.
   - **Caido:** Next-generation lightweight interception proxy written in Rust with decoupled backend/frontend for minimal memory footprint and remote VPS auditing.
   - **Snort:** Signature-based NIDS/NIPS evaluating packet headers and payload contents with customizable preprocessors and rules.

4. **Mobile & Malware Security:**
   - **OWASP Mobile Top 10:** Prioritizes credential usage (M1), supply chain risks (M2), authentication flaws (M3), and communication failures (M5).
   - **Agent Smith & Janus Vulnerability (CVE-2019-2107):** Exploited Android APK Signature Scheme v1 by prepending malicious DEX bytecode to the front of legitimate APKs (which read forwards) while ZIP signatures at the tail remained valid, hijacking applications like WhatsApp without permission warnings.
   - **Frida & Objection:** Enable dynamic instrumentation in mobile memory to override SSL/TLS TrustManagers and bypass certificate pinning at runtime.

5. **IoT & Operational Technology (SCADA / PLC):**
   - **Hardware Reversing:** Identify UART serial pads (GND, VCC, TX, RX) using multimeters to obtain root bootloader shells; dump firmware via JTAG boundary scanning and dissect with `binwalk -Me`.
   - **Purdue Model (PERA):** Segregates industrial systems across Levels 0 to 5. OT prioritizes **Availability and Human Safety (AIC)** over confidentiality.
   - **Modbus TCP (Port 502):** Industrial protocol lacking any encryption, authentication, or integrity checks. Attackers send Function Code `0x05` (Write Single Coil) or `0x06` (Write Register) to disrupt physical machinery.
   - **Defenses:** Fortinet FortiGate Rugged provides inline deep packet inspection (DPI) and zone segmentation; Microsoft Defender for IoT provides zero-risk passive network monitoring via SPAN ports.

6. **Cloud, Containers & Identity:**
   - **Shared Responsibility:** Customer maintains data, access, and IAM across IaaS, PaaS, and SaaS; provider assumes physical and hypervisor management.
   - **Cloud Cryptography:** Transit (TLS 1.3), Rest (Envelope encryption with KMS master keys and data encryption keys), and In-Use (Confidential computing hardware enclaves like Intel SGX / AMD SEV).
   - **Container Breakouts:** Mounting the Docker daemon socket (`/var/run/docker.sock`) inside a container allows launching privileged containers that mount host `/`, yielding immediate host root compromise. Harden via rootless containers, dropped capabilities (`--cap-drop=ALL`), and Falco runtime detection.
   - **Microsoft Graph API:** Exploited via illicit OAuth consent grant phishing (obtaining permanent refresh tokens with `Mail.ReadWrite` / `Directory.AccessAsUser.All`) and Primary Refresh Token (PRT) extraction from `lsass.exe`.

7. **EDR Sensor Mechanics & Stealth Backdoors:**
   - **Elastic Endgame (Elastic Defend):** Monitors system calls via user-space detours in `ntdll.dll` and kernel callbacks (`ObRegisterCallbacks`).
   - **Process Hollowing:** Launches a trusted Windows binary (`svchost.exe`) in a suspended state, unmaps its executable image (`NtUnmapViewOfSection`), allocates RWX memory, copies shellcode, updates thread context, and resumes the thread.
   - **Detection:** Threat hunters identify hollowed backdoors by locating unbacked executable memory (`PAGE_EXECUTE_READWRITE` with `Type: MEM_PRIVATE` rather than `MEM_IMAGE`) and anomalous parent-child execution hierarchies.

8. **Cryptanalysis & Quantum Readiness:**
   - **Attack Models:** Ciphertext-Only Attack (COA), Known-Plaintext Attack (KPA), Chosen-Plaintext Attack (CPA), Chosen-Ciphertext Attack (CCA), and physical side-channel leakages.
   - **Quantum Threat:** Shor's algorithm completely breaks asymmetric encryption (RSA, ECC, Diffie-Hellman). Grover's algorithm provides quadratic speedup, halving symmetric cipher security (AES-128 is weakened, but AES-256 remains resilient with 128-bit quantum security).
   - **NIST Post-Quantum Standards (2024):** FIPS 203 (ML-KEM / Kyber for key exchange), FIPS 204 (ML-DSA / Dilithium for digital signatures), and FIPS 205 (SLH-DSA / SPHINCS+ for stateless hash-based signatures).
