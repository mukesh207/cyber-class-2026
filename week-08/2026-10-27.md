## 🔑 Key High-Yield Core Takeaways

1. **Protocol Enumeration:**
   - **SMB:** Anonymous null sessions (`smbclient -L //target/ -N`) allow discovery of unmapped shares and sensitive credentials that feed directly into offline dictionary attacks (`john --format=NT`).
   - **NetBIOS Suffixes:** Suffix `<00>` identifies workstations, `<20>` flags active File Server Services (SMB), and `<1B>` locates Domain Master Browsers.
   - **SNMP:** MIB trees organize objects hierarchically; OID `1.3.6.1.2.1.25` enumerates running host processes and installed software.
   - **NFS Root Squashing:** `no_root_squash` misconfigurations allow remote clients to write SUID root binaries, yielding trivial local privilege escalation.

2. **Active Directory & Kerberos Security:**
   - **AS-REP Roasting:** Exploits user accounts with `DONT_REQ_PREAUTH` enabled; requires no domain credentials.
   - **Kerberoasting:** Authenticated domain accounts request Service Tickets (TGS) for accounts with registered SPNs and crack them offline (Hashcat mode `13100`).
   - **Golden vs. Silver Tickets:** Golden tickets forge TGTs using the compromised `krbtgt` hash (domain-wide scope, talks to KDC); Silver tickets forge TGS tickets using a service account hash (service-specific scope, completely bypasses Domain Controller logs).

3. **Memory Corruption (Buffer Overflows):**
   - In a stack overflow, user input fills local buffers, overwrites the saved Base Pointer (`EBP`), and hijacks the Instruction Pointer (`EIP`).
   - Modern mitigations combine compiler canaries (`/GS`), hardware execution flags (**DEP/NX**), and kernel address randomization (**ASLR**).

4. **SOC Engineering & YARA:**
   - YARA rules provide deterministic byte and string matching across files and live memory dumps.
   - Crucial for detecting obfuscated web shells and in-memory Cobalt Strike beacon reflective loaders.

5. **Network Layer 2 Defenses:**
   - Mitigate ARP poisoning, MAC flooding, and rogue DHCP servers using **Dynamic ARP Inspection (DAI)**, **DHCP Snooping**, and switch **Port Security**.

6. **Web Application Security:**
   - The OWASP Top 10 evolved significantly in 2021: **Broken Access Control** rose to #1, **Cryptographic Failures** reached #2, and **Insecure Design**, **Software & Data Integrity Failures**, and **SSRF** debuted as new core categories.
   - All 35 classic web application attacks (from Directory Traversal and XXE to DNS Rebinding and MarioNet persistent browser workers) demand defense-in-depth: context-aware encoding, prepared statements, and strict Content Security Policies.
